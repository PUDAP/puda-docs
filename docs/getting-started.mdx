# Getting Started

These docs describe **PUDA CLI v0.1.0** and Python SDK **0.0.17**. Use the version dropdown in the navbar for other releases. See the [v0.1.0 release notes](https://github.com/PUDAP/puda/releases/tag/v0.1.0).

If you are already running **v0.0.36**, follow [Upgrading from v0.0.36](./upgrading-from-0.0.36).

PUDA is a hardware harness for Physical AI. Read more about it at [puda.co/blog/paper](https://www.puda.co/blog/paper).

## What You Will Need

Some experience with Linux and Docker, plus hosts for the AI agent, NATS server, and any machine edge services.

See [Hardware Requirements](./setup/hardware-requirements) for recommended minimums.
